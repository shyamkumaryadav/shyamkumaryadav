## About Me

I am a working professional and a full stack learner who enjoys building practical products and learning by shipping real projects.

My core backend interest is in Django and Django REST Framework, and on the frontend I enjoy working with React and exploring JavaScript frameworks like Vue and Svelte. I also like using Tailwind CSS to build clean and modern interfaces.

I learn best by building, improving, and trying new tools in real projects.

## Projects

### [E_library](https://github.com/shyamkumaryadav/E_library)
This was my college project and one of the projects that really taught me Django. It helped me build a strong base in backend development and understand how to turn a simple idea into a working web application.

### [ePustakalay](https://github.com/shyamkumaryadav/ePustakalay)
This project grew from the same library idea, but here I became much more comfortable with the frontend side. It helped me get familiar with React, Axios, and the overall flow of connecting backend and frontend in a full stack application.

### [gpacalculatorapp](https://github.com/shyamkumaryadav/gpacalculatorapp)
An Android app project that helped me learn something new outside web development. Building it gave me hands-on experience with app development and problem solving in a different environment.
